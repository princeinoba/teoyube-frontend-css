# Phase 11.6B State-of-the-Art Acceptance Criteria

## Standard
For this static local app, "state-of-the-art functional" means user actions change visible app state, can be inspected, can be reversed or saved where appropriate, and remain local, Scripture-rooted, explainable, consent-first, and cautious.

## Criteria
1. User input changes app output.
2. Search filters and scores real local words, promises, Scriptures, and categories.
3. Save actions appear immediately in Book, Journal, or Promise Table.
4. Generated journeys update Today, active journey state, right rail, graph context, and Book memory.
5. Graph Explorer reflects the selected Today/Search/Calling/Guide response.
6. Teo Guide composes structured local responses with Scripture, promise, prayer, action, why-this, confidence, and fallback context.
7. Calling Compass runs a guided flow and uses cautious language.
8. Promise Table supports add, status edit, notes, remove, filter, search, sort, detail, prayer, action, Book save, and export access.
9. Lexicon supports search, filters, detail/study, related words, Scripture anchors, prayer, Book, Promise Table, graph, and study completion.
10. Testimony supports create, status label changes, delete, filter, and export access without automatic fulfillment.
11. Personalization visibly affects previews only after consent and remains off by default.
12. Command palette actions run real contextual actions and show disabled reasons when context is missing.
13. Mobile width must expose major actions without relying on hover-only controls.
14. Every major action shows success, fallback, or error feedback.
15. No primary button may be decorative-only; unsupported capabilities must disclose local-preview/fallback status.

## Completion Gate
Phase 11.6B is complete only when the app itself passes functional QA, manual browser QA is executed, smoke checks pass, and no prohibited service/storage/runtime is added.
