# Phase 11.6B Graph Explorer Report

## Upgrade
Graph Explorer now updates from active Today, Search, Calling, Teo Guide, Book, and Lexicon responses through `updateGraphFromResponse`.

Added graph detail actions:
- save node to Book
- generate prayer
- start action

Node and edge selection now update the smart right rail with the selected graph context.

## Modes Preserved
Existing Phase 11.6 graph modes remain:
- path
- node list
- relationship list
- Scripture evidence
- confidence breakdown

## Mobile
The graph retains its list-first mobile fallback and does not depend on a dense unreadable canvas.

## Safety
Graph relationships are local explanation paths. They are not divine certainty and do not require external services.
