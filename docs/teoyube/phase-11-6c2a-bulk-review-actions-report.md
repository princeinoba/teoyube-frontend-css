# Phase 11.6C.2A Bulk Review Actions Report

Safe batch actions can apply a Bible book, Scripture reference, title prefix, theme, Teoyube word, promise cluster, sequence ID, recommended surface, review status, or pilot selection to selected records.

Every action displays the selected count and preview, requires confirmation, captures one undo snapshot, records operation history, and changes only in-memory review state before export. Applying a Scripture value does not set `mappingConfidence` to `confirmed`. Undo and reset remain available before export.
