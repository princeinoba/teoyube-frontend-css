# Phase 11.6B Calling Compass Report

## Upgrade
Calling Compass now has a guided local flow:
- start compass
- answer capture
- progress indicator
- back/next
- result generation
- Scripture support
- related Teoyube words
- promise cluster
- prayer
- action step
- reflection save
- journey start
- graph view

## Result Language
The result uses cautious wording:
- "Your responses suggest..."
- "This may be an emerging pattern..."
- "Prayerfully test through Scripture, wise counsel, fruit, and time..."

It avoids:
- "God told you..."
- "This is your destiny..."
- "You must..."

## Cross-App Effects
Compass results update active calling result, active TIG response, right rail, graph, Journal, and active journey state.

## Safety
Calling guidance remains devotional, Scripture-submitted, non-diagnostic, and non-professional.
