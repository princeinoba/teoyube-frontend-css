# Phase 11.5 Feedback Controls Report

Feedback controls were added to visible product surfaces so users can shape soft hints explicitly.

## Controls

- More like this
- Less like this
- Not relevant
- Save Scripture
- Save Word
- Save Prayer
- Complete Action
- Reset this preference

## Surfaces

- Today smart recommendations
- TeoyubeSearch result cards
- Promise Table items
- Teo Guide responses
- Canon smart recommendations
- Right insight rail comparison flow
- Personalization Center hint cards

## Behavior

When personalization is enabled, feedback creates visible local/session signals and refreshes preference hints. When personalization is off, save actions can still create visible journey memory, but preference signals are not stored.

Raw private text is never exported by the feedback system.
