# Phase 11.6C.1 Media Surface Recommendations

All recommendations require reviewed derivatives and a gated runtime record. No current draft record is live.

| Surface | Recommended media and behavior | Scripture, accessibility, mobile |
| --- | --- | --- |
| Today | One short contextual animation or poster; muted visible-only motion, never sound autoplay | Show the Scripture anchor and Why this media reason; poster under reduced motion |
| Canon | Journey/sequence poster with user-initiated sequence player | Explain direct Scripture or reviewed sequence relationship; keyboard-operable controls |
| TeoyubeSearch | Searchable poster cards with type, book, reference, duration, and review-safe tags | Filter by media availability; no motion in dense results; responsive list fallback |
| Promise Table | Optional reviewed Scripture/promise companion thumbnail | Media supplements the promise and never replaces Scripture; save only the record ID |
| Calling Compass | Short portrait or landscape prompt after a reviewed calling/Scripture match | Use cautious matching language; no certainty claims; mobile-first poster fallback |
| Book of the Saint | Saved media references and long-form user-initiated playback | Store only approved runtime IDs; no protected path or raw private text in summaries |
| Lexicon | Short pronunciation/concept media or Scripture animation | Explain word-to-Scripture relationship; captions/transcript where relevant |
| Testimony | Optional reviewed visual reference selected by the user | Never infer a testimony claim from media; accessible title and explicit consent boundary |
| Teo Guide | Poster-first recommended teaching, devotional, or audio | Show why it matches, confidence, fallback, and Scripture; no live AI or autoplay |
| Graph Explorer | Media nodes in list fallback, opened only on request | Label relationship type and Scripture evidence; avoid dense autoplay surfaces |
| Embedded Videos | Reviewed video library with category, book, sequence, audio, and length filters | User controls playback; long-form never autoplays; captions, posters, and mobile sizing required |

Save behavior should reference approved runtime IDs, not copy source paths. Search should index reviewed metadata only. Every surface must preserve no-sound autoplay, reduced-motion, poster fallback, keyboard access, visible controls, and safe fallback text.
