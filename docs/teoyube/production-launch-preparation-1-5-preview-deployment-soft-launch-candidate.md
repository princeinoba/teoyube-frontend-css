## Preview Deployment Readiness

The preview readiness module confirms build verification structure, deployment dry-run readiness, safe preview environment defaults, disabled providers, Scripture anchoring, explanation paths, fallbacks, consent controls, offline fallback, mobile QA, accessibility QA, surface readiness, and no launch-critical blockers.

The module does not execute provider commands or create a deployment.

## Preview Environment Package

The preview environment package defines safe feature flags, environment variable placeholders, disabled-until-later services, safety requirements, manual review notes, and rollback notes.

It must not contain real secrets, database connection strings, analytics provider keys, live AI API keys, production persistence enablement, or raw text storage enablement.

## Soft Launch Candidate Plan

The soft-launch candidate planner defines an internal-preview-first plan, launch-critical surfaces, mobile-first QA, Scripture anchoring QA, explanation path QA, fallback/offline QA, consent and feedback QA, accessibility QA, privacy review, manual feedback collection, manual monitoring, and rollback criteria.

This does not implement cohorts, collect real user data, connect analytics, or connect a database.

## Preview Release Notes

Preview release notes state that Teoyube is structurally ready for preview deployment review while production database persistence, external analytics, live AI orchestration, service workers, native mobile builds, paid infrastructure, and production monitoring remain disconnected.

## Rollback and Manual Review Plan

The rollback/manual review plan defines manual review items, go/no-go checks, rollback triggers, and rollback steps. Provider-specific rollback remains manual until the deployment target and execution checklist are approved.

## Preview Deployment Command Guide

The command guide describes preflight, verification, post-check, and manual provider deployment steps conceptually. It does not run deployment commands, install provider CLIs, or expose secrets.
