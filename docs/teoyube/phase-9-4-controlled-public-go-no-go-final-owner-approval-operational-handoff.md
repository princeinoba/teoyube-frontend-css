## Controlled Public Go/No-Go Decision Layer

`controlled-public-go-no-go-contracts.ts` and `controlled-public-go-no-go.ts` create a manual, in-memory go/no-go report across public release preparation, release candidate QA, final regression QA, readiness score, public copy, privacy/consent, sensitive data warnings, known limitations, Scripture anchors, explanation traces, fallback, confidence labels, reviewed content gate, service-disabled state, support readiness, feedback readiness, issue triage, manual monitoring, mobile, accessibility, owner approval, and operational handoff.
