# Phase 11.6 Guided Workflows Report

## Workflows Added
- I need a promise
- Help me pray
- I need calling clarity
- Start a growth journey
- Study a Teoyube word
- Record testimony

## UX
- A Guided Workflow Builder entry point appears in smart recommendation areas.
- Workflows show progress steps, Back, Next, Cancel, and Save Locally.
- Each workflow includes Scripture, promise, word, action, and a Phase 11.6 "Why this?" panel.

## Safety
- Workflow inputs are sanitized and only held in the current local session state.
- Raw private text is not persisted or exported.
- Calling clarity remains cautious and does not declare destiny.
- Testimony workflows do not mark promises fulfilled automatically.

## Limitation
- Workflow steps use local structured UI, not a live AI planner.
