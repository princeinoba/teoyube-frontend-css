# Phase 11.7 Browser QA Checklist

Manual browser QA remains recommended for Phase 11.8.

## Desktop

- Open Data Controls from command palette.
- Open Data Controls from Beta Export Center.
- Download safe JSON and Markdown.
- Select a valid beta JSON export and verify preview counts.
- Select merge new only and confirm sanitized merge behavior.
- Confirm clear session data requires an explicit button click.
- Confirm Promise Table and Testimony data strips do not overlap content.

## Mobile

- Verify Data Controls dialog fits within the viewport.
- Verify import preview controls wrap cleanly.
- Verify offline pill does not block nav or primary buttons.
- Verify Book, Promise Table, Testimony, Personalization, and right rail controls remain reachable.

## Safety

- Confirm no public launch, upload, analytics, account, payment, database, live AI, or automatic contact behavior occurs.
- Confirm Scripture anchors and fallback notices remain visible.
