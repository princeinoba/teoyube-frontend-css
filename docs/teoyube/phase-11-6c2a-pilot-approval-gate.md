# Phase 11.6C.2A Pilot Approval Gate

The controlled pilot requires 12-30 unique short videos, zero to two long-form videos, exactly one owner-confirmed sequence, confirmed Scripture, approved review and safety, confirmed ownership or license, reviewed titles, recommended surfaces, supported source records, and resolved exact duplicates. Estimated public output may not exceed 500 MiB.

The dashboard reports counts, source and projected size, and record-level blockers. It offers no approval action while blockers remain. The default pilot is empty and `blocked`; this is expected and truthful, not a phase implementation failure.

The owner must review and explicitly select every pilot record. No scan result, local suggestion, or batch action auto-approves Scripture or integration.
