# Phase 11.6C.2A Pilot Plan Report

`scripts/planTeoyubeWorldPilot.cjs` merges valid review patches in memory, validates the pilot constraints, and writes a generated plan plus Markdown report. The plan includes selected IDs, canonical choices, sequence and long-form IDs, source size, browser and metadata coverage, poster coverage, derivative requirements, projected public paths and runtime records, processing storage, projected public size, warnings, and blockers.

Planning never copies, transcodes, or promotes a record. The current empty selection writes a blocked plan with zero selected records and zero projected public bytes.
