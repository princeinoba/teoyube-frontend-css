# Teo Guide live AI contract

Live AI is an optional language and synthesis layer in the Next preview. It is not Scripture, revelation, divine speech, a pastor, a clinician, or an authority over the user.

The displayed response must keep exact WEB Scripture, textual context, Teoyube interpretation, prayer language, suggested application, confidence, sources, and limitations distinguishable. Calling language stays tentative. Testimony, promise fulfillment, Book promotion, journey transitions, consent, memory, and all writes remain user-controlled.

A live response is eligible for display only when external-processing consent is effective, sensitive-content consent is effective when required, deterministic tools have completed, every citation matches an exact supplied WEB source, every section uses known source IDs, the strict schema passes, and Prompt 17 post-validation passes. Otherwise Teo Guide uses the deterministic response.

The user can choose deterministic mode, cancel a request, revoke consent, and continue without live AI. `store: false` is enforced, and Teoyube does not claim provider Zero Data Retention.
