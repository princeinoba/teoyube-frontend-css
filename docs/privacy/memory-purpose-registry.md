# Memory Purpose Registry

| Purpose | Layers/classes | User decision | Retention |
| --- | --- | --- | --- |
| `preference_continuity` | Semantic preference / Class 1 | Explicit grant and save action | 730 days |
| `journey_continuity` | Journey state or episodic metadata / Class 2 | Explicit grant and save action | 730 days |
| `sensitive_spiritual_storage` | Episodic private content / Class 3 | Separate grant plus explicit content approval | 365 days |
| `testimony_book_continuity` | User-confirmed episodic or journey state / Class 2 or 3 | Separate grant; draft text also needs sensitive approval | 365 days |

Purposes are default-off and cannot be bundled. Effective scope must permit the exact read, write, export, or deletion operation. Revocation applies immediately to the whole purpose and removes its active content from Teo Guide, TIG personalization, Search personalization, and journey retrieval.

TIG recommendation IDs, confidence, limitations, and acceptance/rejection are evidence. The registry forbids deterministic-system fields that declare calling, divine certainty, promise fulfillment, testimony publication, spiritual worth, or God's action as fact.
