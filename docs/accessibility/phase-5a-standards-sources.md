# Phase 5A standards sources

Verified on 2026-08-05 from official W3C publications.

| Source | Status used by Phase 5A | Role in the audit |
| --- | --- | --- |
| [Web Content Accessibility Guidelines (WCAG) 2.2](https://www.w3.org/TR/WCAG22/) | W3C Recommendation, 12 December 2024 | Normative A/AA conformance target and criterion identifiers. |
| [Accessible Rich Internet Applications (WAI-ARIA) 1.2](https://www.w3.org/TR/wai-aria-1.2/) | W3C Recommendation, 6 June 2023 | Normative role, state, property, and accessible-name requirements. |
| [ARIA in HTML](https://www.w3.org/TR/html-aria/) | W3C Recommendation, 15 April 2026 | Normative HTML/ARIA authoring constraints. |
| [ARIA Authoring Practices Guide](https://www.w3.org/WAI/ARIA/apg/) | WAI guidance, not a normative conformance standard | Informative interaction-pattern and keyboard-design reference. |
| [WCAG 3.0](https://www.w3.org/TR/wcag-3.0/) | Working Draft, 3 March 2026 | Informative future direction only; not used to claim conformance. |

The audit also read the complete product-source PDFs under `docs/product-source/` that govern Scripture authority, promise levels, cautious calling language, Teoyube-word boundaries, user confirmation, reversibility, and sensitive-topic handling. Those product rules inform risk and content review but do not replace WCAG, WAI-ARIA, or ARIA in HTML.

## Interpretation rule

- A successful axe rule is evidence for that rule in that rendered state, not a WCAG conformance claim.
- APG examples are implementation guidance, not a substitute for normative HTML and ARIA requirements.
- WCAG 3.0 results are not reported because its current Working Draft is not an approved conformance target.
- Criteria requiring human judgment, assistive-technology output, media review, cognition review, or physical-device input remain explicitly incomplete until that evidence exists.
