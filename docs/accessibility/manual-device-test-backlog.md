# Manual device and assistive-technology backlog

## P0 before a conformance claim

- Narrator + Edge and Narrator + Chrome: all 23 routes, with focus on Today hidden slides, Canon media controls, Search, Promise Search, dialogs, labels, and status messages.
- NVDA + Chrome/Firefox: the same task set when NVDA and Firefox are available.
- Manual contrast review of 3,674 axe-incomplete nodes, especially text over artwork, gradients, disabled states, focus indicators, and forced-colors mode.
- Caption, transcript, audio-description, title, keyboard, and focus behavior for every externally hosted media item.
- Human focus-obscuration review at every sticky header, rail, toast, modal, player overlay, skip link, and mobile drawer.

## P1 before broad pilot use

- VoiceOver on macOS Safari and iOS Safari.
- TalkBack on Android Chrome.
- Physical keyboard on tablet and phone.
- 200% and 400% browser zoom; Windows Magnifier; macOS Zoom; mobile font scaling.
- Touch target and gesture testing on 320–390 CSS-pixel devices, including all carousel dots and compact filters.
- Speech input for visible-label/accessibility-name equivalence.
- Switch control and reduced-dexterity workflows.

## P2 product-quality validation

- Braille display reading order, landmarks, tables, live regions, abbreviations, and Scripture citations.
- Cognitive walkthrough for errors, limitations, consent, reversibility, and cross-module continuity.
- Low-vision review of images of text, hero art, badges, charts, progress indicators, and focus contrast.
- Real-user accessibility pilot with the already approved synthetic-scenario and consent boundaries; do not create participants automatically.

All testing must use synthetic content unless a separately consented research protocol authorizes otherwise. No item in this backlog authorizes a product change or Phase 5B implementation.
