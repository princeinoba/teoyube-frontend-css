# Data-minimization card

Collect only fixed event names, scenario/task IDs, routes, completion codes, rescue counts, safe issue codes, consent-record references, source IDs, accessibility mode codes, bounded ratings, duration buckets, cohort, and integrity metadata.

Never collect names, contact details, diagnoses, denominations, church data, precise location, raw search or prompt text, model input/output, prayer, journal, reflection, testimony, memory, check-in, health, trauma, abuse, relationship, crisis, Scripture quotation text, credentials, tokens, free text, holiness/faith/favor scores, spiritual ranks, or engagement-pressure metrics.

If uncertain, do not record it. Stop and consult the privacy lead.
