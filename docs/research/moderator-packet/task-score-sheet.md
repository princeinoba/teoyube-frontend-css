# Task score sheet

**TEMPLATE — DO NOT ENTER REAL PARTICIPANT DATA IN THE REPOSITORY**

Use predefined codes. Do not write raw participant narratives.

| Field | Allowed codes |
| --- | --- |
| Outcome | `SUCCESS`, `PARTIAL`, `FAIL`, `STOPPED`, `SKIPPED`, `WITHDRAWN` |
| Rescue | `R0_NONE`, `R1_REPEAT`, `R2_NEUTRAL_ORIENTATION`, `R3_POINT_REGION`, `R4_NAME_CONTROL`, `R5_SAFETY_STOP` |
| Authority | `AUTH_CORRECT`, `AUTH_SCRIPTURE_INTERPRETATION_CONFUSED`, `AUTH_AI_DIVINE_CONFUSED`, `AUTH_CALLING_CERTAINTY_CONFUSED`, `AUTH_TESTIMONY_OWNER_CONFUSED`, `AUTH_FULFILLMENT_CONFUSED` |
| Privacy | `PRIV_OK`, `PRIV_REDIRECTED`, `PRIV_CONSENT_UNCLEAR`, `PRIV_WITHDRAWAL`, `PRIV_DELETION_REQUEST` |
| Accessibility | `A11Y_NONE`, `A11Y_FOCUS`, `A11Y_NAME`, `A11Y_REFLOW`, `A11Y_SCREEN_READER`, `A11Y_MOTION`, `A11Y_MEDIA`, `A11Y_ERROR` |
| Safety | `SAFE_NONE`, `SAFE_PRIVATE_DISCLOSURE_STOP`, `SAFE_DISTRESS_STOP`, `SAFE_CRISIS_STOP`, `SAFE_PROVIDER_STOP` |
| Duration | `UNDER_1M`, `1_TO_3M`, `3_TO_5M`, `OVER_5M`, `NOT_MEASURED` |

Record scenario ID, task ID, route, outcome, rescue count/code, safe issue code, and bounded rating only. Free-form notes belong outside the event system and are not authorized by this phase.
