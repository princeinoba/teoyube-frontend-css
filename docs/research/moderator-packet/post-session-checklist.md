# Post-session checklist

**TEMPLATE — DO NOT ENTER REAL PARTICIPANT DATA IN THE REPOSITORY**

- [ ] Session ended, skipped, stopped, or withdrawn status is coded.
- [ ] No private content or contact data entered the event store.
- [ ] Optional live-AI consent is revoked or recorded according to the reviewed process.
- [ ] Recording disposition follows the separate consent choice.
- [ ] Withdrawal/deletion request was actioned or escalated.
- [ ] Any adverse event is resolved or remains an explicit blocker.
- [ ] Ordinary and expert cohorts remain separate.
- [ ] Synthetic product state is reset.
- [ ] Export is regenerated after deletion when applicable.
- [ ] Temporary listeners are closed.
- [ ] Participant receives the debrief and approved contact process.
