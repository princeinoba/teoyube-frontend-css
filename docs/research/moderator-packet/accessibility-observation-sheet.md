# Accessibility observation sheet

**TEMPLATE — DO NOT ENTER REAL PARTICIPANT DATA IN THE REPOSITORY**

Confirm `research_accessibility_observation` consent. Ask what accommodation is useful; never demand a diagnosis.

For each assigned scenario, record only task/scenario ID, accessibility mode code, completion code, rescue code, severity code, and one of the fixed barrier codes from the task score sheet. Observe keyboard reachability, focus visibility/order, accessible names, 200% zoom/reflow, screen-reader announcements, reduced motion, media controls, error association, consent, sources, and deletion.

Stop when continuing causes distress, fatigue, consent uncertainty, or a high-impact safety/access barrier. Ordinary usability results and accessibility observations remain distinguishable in analysis.
