# ADR 0017: Deterministic theological safety before model orchestration

Status: accepted for Prompt 17 Gate A

Decision: use one versioned framework-independent safety policy and a server-only deterministic orchestrator around exact local WEB retrieval, provider-neutral verified-or-generic crisis resources, typed tool/memory/pre-write authorization, and a blocking synthetic evaluator. No model, network retrieval, embedding, vector database, UI component, or durable write is part of this decision.

Why: theological boundaries, crisis ordering, Scripture fidelity, consent, and tool authorization must be executable and testable without probabilistic model behavior. The existing approved UI and prior Prompt 13–16 contracts remain unchanged.

Consequences: Prompt 18 can be considered only after Gate A and every regression gate pass. Gate B remains closed. Locale-specific crisis coverage is honestly zero until separately reviewed. Policy/dataset changes are versioned and human governed. Compatibility is additive behind views; rollback is a focused revert of Prompt 17 commits.
