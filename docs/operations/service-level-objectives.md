# Preview and release service-level objectives

Version: `teoyube-preview-slo-2026-07-24.1`

These are synthetic local/CI objectives. They are not production uptime or
traffic claims.

## Correctness invariants

These have no error budget:

| Objective | Target | Evidence |
| --- | ---: | --- |
| Displayed WEB citation validity | 100% | Scripture gate |
| Critical immediate-danger fixture recall | 100% | Gate A |
| Cross-user data exposure | 0 | Memory/retrieval contract tests |
| Unauthorized memory, tool, or state action | 0 | Critical-contract tests |
| Fabricated Scripture displayed | 0 | Citation validation |
| Protected visual or baseline drift | 0 | Recovery/parity gates |

## Synthetic preview objectives

| Service | Objective | Window and evidence |
| --- | --- | --- |
| Next preview under automated test | 100% required journey completion | Each release-evidence run |
| Non-AI API | 100% critical-route success; p95 <= 250 ms locally | Release performance artifact |
| Authenticated repository | 100% contract success | Integration suite |
| Deterministic fallback | 100% when provider is unavailable | Live-AI offline suite |
| Live-AI preview | Owner-tagged Gate B-Preview pass | Hash-bound reuse only when dependencies are unchanged |
| Hybrid retrieval | Recall/MRR/nDCG thresholds from Prompt 20 scorecard | Retrieval gate |
| Deletion and revocation | 100% completion in bounded test storage | Memory/retrieval integration |
| Route readiness | <= 5,000 ms | Existing visual readiness contract |
| Browser journey | 100% critical scenarios complete | E2E suites |
| Visual performance | 216/216 cells pass across three runs | Resumable gate |

Prompt 20 recorded a local retrieval p95 baseline of 304.2182 ms; the
non-regression release limit is 334.64 ms. All other current p50/p95/p99
measurements are generated by `npm run release:performance:verify` and belong
to the commit in its artifact.

Production availability, provider latency, deletion queue completion, and
alert response objectives remain unproven until production infrastructure and
real traffic exist. They must be reset from measured production data after a
separate cutover approval.
