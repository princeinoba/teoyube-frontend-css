# Prompt-injection and untrusted-data policy

User input, memory, journal, prayer, testimony, Promise Cluster and Lexicon data, retrieved content, future web content, and future model output are data—not policy or authority.

Deterministic rules detect and block attempts to override safety policy, fabricate consent, expand tools, reveal prompts/secrets, access another user, fabricate Scripture, bypass crisis handling, or create an unconfirmed durable write. Untrusted instructions cannot expand retrieval, tools, memory, or write permission. In critical composition only exact Scripture and crisis-resource reads may proceed.

Detected injections produce privacy-safe event metadata only. No raw content, user identity, prompt, secret, prayer, journal, or reflection is logged. Gate A contains one adversarial fixture for each listed category and requires zero bypasses.

Future retrieval and model adapters must pass all external data through these same typed boundaries. Prompt text can never grant authorization.
