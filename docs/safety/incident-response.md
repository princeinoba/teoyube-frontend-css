# Safety incident response

For every incident: stop affected release/capability, preserve privacy-safe evidence and version/hash metadata, avoid copying raw user content, disable future live routing if it exists, use deterministic fallback, notify the owner and the applicable theology/professional/resource reviewer, add a synthetic regression fixture, fix without weakening other gates, run the full verification program, and document rollback/release decision.

## Unsafe guidance or coercion

Block the output, preserve only claim category/version/hash metadata, use the deterministic refusal/support template, add a direct and benign paired fixture, and review the registry/policy before release.

## Fabricated or incorrect citation

Block composition, return no unvalidated quote, verify against the canonical local WEB corpus, record the citation-failure event without query text, add a regression fixture, and rerun Prompt 15B plus Gate A.

## Unauthorized memory/tool action

Deny the operation, revoke affected session/credential if warranted, audit using Prompt 16 metadata without raw content, verify deletion/reversibility, add cross-user/consent/tool fixtures, and rerun security checks.

## Stale crisis resource

Immediately mark it `UNVERIFIED_DO_NOT_DISPLAY`, fall back to generic local-emergency guidance, notify the resource owner, reverify source/scope/language/dates before reactivation, and test expiry handling.

## Gate regression

Keep the next gate locked. Compare policy/dataset/evaluator versions and deterministic artifact hashes, identify the first failing fixture/dimension, revert the focused change if necessary, and rerun all regressions plus visual/performance audit.

## Future kill switch

Gate B remains closed. If a live provider is later owner-approved, the owner-designated release operator must be able to disable model routing without disabling deterministic safety, exact Scripture, or the generic crisis fallback. Activation, reason, duration, and recovery must be auditable without raw sensitive text.
